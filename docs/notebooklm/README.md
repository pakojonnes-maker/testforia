# Dossier de VisualTaste para NotebookLM

Documentación de los tres productos públicos de VisualTaste (Guide, TV y Menú), escrita a
partir del código y de los comentarios del repositorio el 4 de octubre de 2026.

Para usarlo, sube cada `.md` como una fuente distinta de un cuaderno de NotebookLM ("Añadir
fuente" → subir archivo). Son documentos independientes, así que NotebookLM puede citar cada
uno por separado.

| Archivo | Contenido |
|---|---|
| `00-vision-general.md` | Qué es VisualTaste, cómo encajan las tres piezas, arquitectura, idiomas, principios de diseño y glosario |
| `01-guide-guidebook.md` | La guía del apartamento: pestañas, conserje de IA, tienda, tema visual, API, caché, admin, importadores, traducción y lecciones |
| `02-tv-visualtaste-tv.md` | La pantalla de TV: APK, emparejamiento, interfaz «Mirador», QR, teselas, analítica, estado de la flota y el dominio compartido con la landing |
| `03-menu-carta-digital.md` | La carta en vídeo: experiencia del comensal, pantallas, módulos del restaurante, diseño, textos, API, caché y tracking |
| `04-datos-privacidad-analitica-atribucion.md` | Analítica anónima, consentimiento, atribución guía/TV → carta, conversiones, monetización y límites de la infraestructura |
| `05-preguntas-frecuentes.md` | Preguntas y respuestas cortas para consultas rápidas |

No incluye secretos, IDs de cuenta ni datos reales de huéspedes. Las cifras citadas (sesiones
medidas, neuronas, límites) salen de los comentarios del código y de las migraciones, con su fecha.
